# roms

No game ROMs or BIOS files are included in this repository.

The NES Box theme used by the Pocket AIS image is under
`rootfs/pocketais/home/ark/.emulationstation/themes/es-theme-nes-box`
(and is part of the rootfs overlay tar).  `roms/themes/` is a placeholder that
matches the arkos4clone layout; add only redistributable themes here.

The base images' `/roms` data (games, BIOS, saves) must be backed up before
flashing and is never part of this repository.
